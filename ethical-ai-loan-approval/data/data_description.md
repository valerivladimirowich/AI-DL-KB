# Data Description

This folder contains a small synthetic sample dataset for demonstration only.

## Columns
- `income`: applicant annual income
- `credit_score`: credit score
- `loan_amount`: requested loan amount
- `employment_years`: years of employment
- `age`: protected attribute example
- `gender`: protected attribute example
